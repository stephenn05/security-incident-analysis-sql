# Security Incident Analysis SQL

Учебный проект по анализу данных об инцидентах информационной безопасности с использованием SQL.

## О проекте

Проект демонстрирует применение SQL для аналитической обработки данных об инцидентах информационной безопасности.

В рамках проекта исследуются типы угроз, критичность инцидентов, затронутые информационные системы и показатели риска.

## Аналитические задачи

В проекте реализованы SQL-запросы для:

* подсчёта общего количества инцидентов;
* анализа распространённости различных типов угроз;
* анализа уровня критичности;
* расчёта среднего показателя риска;
* поиска наиболее критичных инцидентов;
* анализа наиболее уязвимых систем;
* анализа динамики инцидентов по месяцам;
* выявления инцидентов с высоким уровнем риска.

## Используемые технологии

* SQL
* Microsoft SQL Server
* GROUP BY
* агрегатные функции COUNT и AVG
* сортировка и фильтрация данных
* анализ временных периодов

## Как использовать

Сначала необходимо выполнить `data.sql` для создания таблицы и загрузки учебных данных.

После этого можно выполнять запросы из `analysis.sql` для проведения анализа.

## Пример аналитического вывода

На основе анализа можно определить наиболее распространённые типы угроз, системы с наибольшим количеством инцидентов и категории с наиболее высоким средним уровнем риска.

Полученные результаты могут использоваться для определения приоритетных направлений мониторинга информационной безопасности.

## Цель проекта

Проект выполнен в учебных целях для развития навыков работы с базами данных, SQL и аналитической обработки информации в области информационной безопасности.
